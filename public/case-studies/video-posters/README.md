# Video-Thumbnails (Case Studies)

**Hier legst du deine WebP/PNG-Dateien ab** – direkt in diesem Ordner.

1. Bild speichern, z. B. `ali.webp`
2. In `app/(website)/testimonials-data.ts` beim passenden Case eintragen:

   `videoPosterSrc: "/case-studies/video-posters/ali.webp"`

Der Pfad beginnt immer mit `/case-studies/video-posters/` + Dateiname.
